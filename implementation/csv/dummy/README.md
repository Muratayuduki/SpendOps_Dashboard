# 発表用ダミーCSV

このフォルダーには、SpendOps Dashboardの発表・画面確認に使用する架空の取引データを格納しています。氏名、実在の取引番号、実際の利用先、カード情報は含みません。

## 発表時に使用するファイル

最も簡単に確認する場合は、次の1ファイルだけをアップロードします。

- `dummy_normalized_transactions.csv`

PayPay、JCB、三井住友VISAの取込形式を個別に確認する場合は、次の3ファイルを同時にアップロードします。正規化済みCSVと同じ取引を支払い元別に分割しているため、正規化済みCSVとの重複アップロードはしないでください。

| 支払い元 | ファイル | 文字コード |
|---|---|---|
| PayPay | `paypay/Transactions_dummy_20260101-20260902.csv` | UTF-8 |
| JCB | `jcb/20260101-20260902_meisai_dummy.csv` | Shift_JIS |
| 三井住友VISA | `visa/smbc_visa_dummy_20260101-20260902.csv` | Shift_JIS |

各支払い元フォルダーに残っているファイル名が202606だけのCSVは、以前の6月限定データです。今回の発表では使用しないでください。

## データ条件

- 期間は2026年1月1日から9月2日までで、1月から9月の全月に取引があります。
- 9月は2026年9月2日時点の暫定月です。
- 全期間の支出総額は151,000円です。直前の発表用データ340,000円から、その他以外のカテゴリ金額をおおむね維持しつつ「その他」を20%まで削減しました。
- SpendOps Dashboardの固定11カテゴリがすべて存在します。
- 「その他」は全支出の20.0%です。その他以外は直前データの金額感とカテゴリ間の大小関係をおおむね維持しています。
- 取引内容、利用先、利用者、取引番号はすべて発表用の架空データです。

| カテゴリ | ダミーデータの構成比 |
|---|---:|
| その他 | 20.0% |
| 食費 | 35.1% |
| ネットでの購入 | 18.2% |
| 日用品 | 10.8% |
| 衣服費 | 6.5% |
| 娯楽 | 2.0% |
| 医療費 | 2.0% |
| 光熱費 | 1.8% |
| 通信費 | 1.6% |

| 交通費 | 0.9% |

## 2人目の比較用データ

`person2/dummy_normalized_transactions_person2_20260101-20260902.csv`は、別人物として比較表示を確認するための正規化済みCSVです。

- 全期間の支出総額は150,800円で、既存ダミーの151,000円と同程度です。
- 月別総額は既存ダミーと異なる増減順にしています。
- 固定11カテゴリをすべて含み、各カテゴリの全期間構成比を2%から20%に収めています。
- 食費中心の既存ダミーとは異なり、住居費、交通費、娯楽、医療費などへ支出を分散しています。
- 利用先名、取引番号、利用者IDは既存ダミーと重複しません。月別総額とカテゴリ配分も既存ダミーと異なります。
- 既存ダミーと同時に読み込む場合も、別の利用者アカウントを使用してください。

## 再生成

```powershell
powershell -ExecutionPolicy Bypass -File implementation\csv\tools\generate_dummy_data.ps1
powershell -ExecutionPolicy Bypass -File implementation\csv\tools\generate_dummy_data_person2.ps1
```

生成スクリプトは、対象月、総額、カテゴリの存在を検証し、条件を満たさない場合はエラーで終了します。

## 全期間表示の確認

レポート期間で「読み込んだ全期間のまとめ」を選ぶと、月別棒グラフと集計対象は2026年1月から9月までになります。支払い明細画面は新しい日付順のページ表示であるため、先頭ページには9月分が表示されます。前の月の明細は「次へ」で確認できます。
