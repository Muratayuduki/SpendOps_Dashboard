# 匿名化比較データバックアップ

## 現在のバックアップ

| 項目 | 内容 |
|---|---|
| AWSリージョン | `ap-northeast-1` |
| バックアップ名 | `spendops-anonymized-comparison-20260723` |
| 種別 | DynamoDBオンデマンドバックアップ（`USER`） |
| 状態 | `AVAILABLE` |
| 保持 | 手動削除するまで保持。容量と保持期間に応じて課金 |
| データ件数 | 月別集計60件 |
| 匿名参加者 | 3人 |

バックアップARNやAWSアカウント番号はドキュメントへ保存しません。復元時はバックアップ名からAWS CLIまたはAWSコンソールで対象を特定します。

## 保持している項目

- 対応表を残さないランダムな匿名ID
- 月と支払い種別
- 月間支出総額
- 取引件数
- 固定カテゴリ別集計
- 支払い方法別集計
- 暫定月フラグ
- スキーマバージョン

## 保持していない項目

- Cognitoユーザー情報
- 元のCognitoユーザーID
- 元ユーザーIDと匿名IDの対応表
- 個別取引
- 利用先・店舗名
- CSV原本、ファイル名、未加工行
- 取込履歴
- 分類ルール
- メールアドレス、認証情報

## 作成時の検証

- 元の月別集計60件と匿名化後60件が一致
- 元の参加者3人と匿名参加者3人が一致
- 月間支出総額の合計が匿名化前後で一致
- 匿名IDがランダムID形式であることを確認
- 許可した比較項目以外の属性が0件であることを確認
- バックアップが `AVAILABLE` になった後、一時復元テーブルと匿名化用テーブルを削除

## AWSシステムバックアップの扱い

DynamoDBが自動作成した未匿名のシステムバックアップはAWS側で早期削除できませんでした。復元やコピーは行わず、次の期限で自動失効するのを待ちます。

| 自動失効日 | 件数 |
|---|---:|
| 2026-08-19 | 4件 |
| 2026-08-27 | 4件 |

長期保持対象は `spendops-anonymized-comparison-20260723` だけです。

## 再構築時の注意

- このバックアップを直接本番テーブル名へ復元せず、確認用の新しいテーブルへ復元する
- 復元後に件数、匿名ID形式、許可属性、集計総額を再検証する
- 匿名参加者は3人のため、このデータだけでは「他5人以上」の実比較条件を満たさない
- 新しいユーザーの月別集計と合わせて比較へ使う場合も、匿名アーカイブから本人を再識別する機能は作らない
- 復元・再投入のPlanと影響を提示し、ユーザー承認後に実施する
